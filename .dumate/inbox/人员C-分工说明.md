## 接口依赖

使用的后端接口（由人员A提供）：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/users` | GET | 获取用户列表 |
| `/api/users` | POST | 新增用户 |
| `/api/users/:id` | PUT | 修改用户信息 |
| `/api/users/:id` | DELETE | 删除用户 |
| `/api/users/:id/role` | PUT | 修改用户角色 |
| `/api/users/:id/status` | PUT | 修改用户状态 |

## 使用说明

### 启动项目

```bash
# 1. 启动后端
cd hotel-backend
python app.py

# 2. 启动前端
cd hotel-frontend
npm run dev
```

1. 使用管理员账号登录
2. 访问 `/users` 路由

## 注意事项

1. **权限控制**：用户管理页面仅管理员可访问
2. **安全限制**：
   - 不能删除当前登录账号
   - 不能禁用当前登录账号
   - 不能取消当前管理员的管理员权限
3. **数据验证**：
   - 用户名不能为空
   - 新增用户时密码必填
   - 手机号格式验证
